# Pre-Windows source closure program

## Goal

Complete every Prime Studio improvement that can be implemented and honestly verified in repository CI before running the application against a real Windows installation and subscription-backed Prime environment.

## Working method

Each coherent scope uses its own branch and pull request:

1. add or strengthen tests;
2. implement the source change;
3. update the machine-readable acceptance and evidence ledger only when supported;
4. run the required CI and Security workflows;
5. independently review the complete pull-request diff and failures;
6. merge only when green and review findings are closed.

A fixture, fake daemon, Linux browser shell, or repository-only test must never be represented as Windows-host, provider-account, signing, browser-effect, or computer-use evidence.

## Source-only work queue

- Common interaction closure: global-shortcut priority, popover and menu behavior, full responsive-state matrix, and managed-control explanations.
- Source-owned General, Git, Environment, Privacy, and account settings behavior.
- Account-usage ledger enrichment and accessible chart/breakdown reconciliation where source data permits.
- Editor and Canvas buffer persistence with identity isolation and conflict-safe recovery.
- Attachment authority and draft lifecycle up to the verified upstream prompt boundary.
- Visual-regression baselines for representative themes, widths, zoom, settings, inspector, editor, and overlays.
- Incremental `StudioApp` orchestration decomposition without changing authority behavior.
- Incremental native-root decomposition and removal or isolation of legacy execution paths.
- Browser/computer-use worker protocol, fake worker, cancellation/takeover, and evidence tests without enabling production effects.
- Prime protocol extension proposals and exact optional-capability profiles for currently unavailable creation, attachment, and tool authorities.
- Disposable-Windows preflight/evidence scripts and schemas, written and CI-tested without claiming host execution.
- Unsigned local-beta build workflow and release-evidence packaging, kept distinct from an official release.
- Dependency-update review after product changes stabilize.

## Stop condition before Windows work

The source-only program stops when every remaining acceptance row requires one of:

- a real exact installed Prime closure;
- a real provider or subscription account;
- Windows, WebView2, or process-containment evidence;
- a production browser/computer effect worker;
- code-signing or update credentials;
- independent release or security approval;
- an upstream Prime capability that does not exist in the reviewed contract.
