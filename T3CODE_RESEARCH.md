# T3Code review boundary

T3Code is an external agent-interface project reviewed as comparative product research. Prime
Studio does not import its source, assets, generated output, or style values.

The project may inform broad, non-exclusive lessons common to developer tools: keep context usage
legible, separate provider telemetry from session cost, preserve calm empty states, and place
session controls close to the session they affect. Prime Studio implements those ideas from its own
runtime contracts, component architecture, accessibility requirements, and woven-aperture brand.

The exact external revision and license classification remain recorded in
[`provenance/NOTICE.md`](provenance/NOTICE.md). That record is an audit boundary, not
authorization for direct reuse. The required posture remains learn/adapt only unless a future
path-specific provenance review records a different verified decision.
